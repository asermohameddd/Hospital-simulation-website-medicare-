# MediCare Hospital Website

A modern and responsive hospital website built using HTML and CSS.

The website provides a clean and user-friendly interface for exploring hospital services, doctors, departments, and contacting the hospital.

## Features:

- Fully Responsive Design optimized for different screen sizes.
- Modern and clean user interface.
- About Us page.
- Doctors page.
- Departments page.
- Appointment page.
- Emergency page.
- Contact Us page.
- Navigation between different website pages.
- Clean layout built using CSS Flexbox.
- User-friendly design for a hospital website experience.

## Technologies Used:

- HTML5
- CSS3
